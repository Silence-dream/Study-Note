```shell

# 实际使用一般来说 node-sass 是业界毒瘤,用 dart-sass 就可以替换掉 node-sass
npm install node-sass@npm:dart-sass
# 如果你使用的是 yarn
yarn add node-sass@yarn:dart-sass
```

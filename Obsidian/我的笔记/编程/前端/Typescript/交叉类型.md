# 交叉类型（Intersection Types）

交叉类型实际上就是数学概念中的并集概念，取集合 A 与集合 B 组在一起的集合

```ts
interface A {
  a: number
}

interface B {
  b: string;
  c: number;
}

// 交叉类型在数学上的理解就是 `并集` 而不是交集(切记)
let c: A & B = { a: 1, b: '2', c: 3 };
```

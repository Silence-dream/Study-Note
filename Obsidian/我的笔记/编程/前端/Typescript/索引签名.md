索引签名(Index Signature)

当你不知道对象里面会传入什么的时候使用也就是只知道键和值


```ts
interface Person {
	[key:string]:string
}

// 模板字面量
interface I {

  [key: `${string}face`]: any

}

let test: I = { idface: "123",nameface:"321" }
```
